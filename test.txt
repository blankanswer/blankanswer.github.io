# TACO算法的RL优化框架（简化版）

# 初始化
1. 准备策略网络π_θ（生成DNA序列的模型）
2. 加载预训练的Enformer模型（计算适应度奖励）
3. 初始化爬山重放缓冲区D（存储高适应度序列）
4. 设置熵正则化系数α

# 迭代优化（共N轮）
for 迭代次数 in 1..N:
    # 步骤1：生成序列并计算奖励
    生成一批序列S = [s1, s2, ..., sM]（通过π_θ采样）
    对每个序列s in S:
        计算fitness奖励r_fitness = Enformer模型预测(s)
        计算TFBS奖励r_TFBS（逐碱基检查是否形成激活/抑制型TFBS）
        总奖励R = r_fitness + r_TFBS
        将(s, R)存入缓冲区D
    
    # 步骤2：更新缓冲区（爬山机制）
    保留D中适应度最高的K条序列
    用新生成的高奖励序列替换D中的低奖励序列
    
    # 步骤3：更新策略网络
    从D中采样一批样本(s, R)
    计算策略梯度：
        基础梯度 = 平均(R * ∇θ log π_θ(s))  （REINFORCE核心）
        熵正则项 = α * 平均(∇θ H(π_θ(s)))  （促进探索）
        总梯度 = 基础梯度 + 熵正则项
    用总梯度更新策略参数θ（梯度上升最大化奖励）

# 输出结果
最终策略π_θ生成的高适应度、高多样性CRE序列
